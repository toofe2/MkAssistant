# MkAssistant

Voice-first AI copilot for iPhone + CarPlay.

**Core flow:** Hey MK → listen → understand → act → speak.

## Target
- iOS 15.6.1+
- TrollStore development/testing
- Iraqi Arabic, Arabic, English, and mixed speech
- Independent from MkCar / CarTube-Premium

## Phase 1
- Voice state machine
- Wake-word engine abstraction
- Speech recognition
- AI agent/orchestrator
- Text-to-speech
- Follow-up conversation window
- Interruption/cancel support

CarTube-Premium is reference-only and is not modified by this repository.
